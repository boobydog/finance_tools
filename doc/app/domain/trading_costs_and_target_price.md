# 取引コスト計算とターゲットプライス算出

## 1. 手数料・税引後の想定純損益(純損益ゲート)

### 要件

[利確判定](trade_judgment.md)は、現在値がターゲットプライスに達したかどうかで判断しているが、これは手数料・税金を考慮しない「額面上の損益」でしかない。含み益がわずかな場合、手数料と譲渡益課税を差し引くと実質的に利益が出ない、あるいは損失になることがある。この誤検知を防ぐため、保有銘柄ごとに手数料・税引後の想定純損益を計算し、利確判定の最終ゲートとして使う(純損益が黒字でなければ利確シグナルとして扱わない)。

### 計算式

```
純損益 = (売却額 - 売却手数料) - (購入額 + 購入手数料) - 譲渡益課税
譲渡益課税 = max(0, 上記の黒字額) × 税率
```

売買手数料は、約定代金の金額帯ごとの片道手数料テーブル(`trading_fee_tiers`)で管理し、設定画面から編集できること。税率(譲渡益課税、既定20.315%)も設定画面から編集できること。

### 複数回の買い増し・口座種別への対応

複数回の買い増しに対応するため、**口座種別(特定・一般口座 / NISA口座)ごとに残存数量・加重平均取得単価を分けて計算し、それぞれの純損益を合算する**こと。NISA口座は譲渡益非課税・手数料無料として扱う(commission=0, tax=0)。同一銘柄がNISA・特定/一般の両方に残存ポジションを持つ場合、口座種別は`mixed`として扱い、表示上は両方の内訳を示せるようにする。

単純に全体の平均取得単価で計算すると、NISA分にまで誤って課税してしまう等の誤りが起きるため、必ず口座種別ごとに独立計算してから合算すること。

### 参考値

- 譲渡益課税の税率: 20.315%(特定口座(源泉徴収あり)/一般口座の標準税率、NISAは0%扱い)
- 売買手数料: 約定代金の金額帯別ティア(下表はSBI証券の現物取引「スタンダードプラン」を参考に設定した現状値。証券会社・プランによって異なるため、実際に利用している手数料表と照合すること。SBI証券の「ゼロ革命」等、条件を満たすと無料になる制度もある)

| 約定代金 | 手数料(片道) |
|---|---|
| 〜5万円 | 55円 |
| 〜10万円 | 99円 |
| 〜20万円 | 115円 |
| 〜50万円 | 275円 |
| 〜100万円 | 535円 |

## 2. ターゲットプライス(目標株価)の算出ロジック

### 要件

利確判定の達成度は、以下の優先順で採用したターゲットプライスを使うこと。

1. 手動設定値(ユーザーが直接入力した値)
2. **購入時点のスナップショット**(購入時に算出し以後固定。現在値変動の影響を受けない)
3. 現在値ベースの自動算出値(保有・候補銘柄の指標更新の都度再計算)

購入時点のスナップショットを優先する理由: 現在値ベースの自動算出値をそのまま使うと、株価が下落した際にターゲットプライス自体も一緒に下がってしまい、達成率が実態と無関係に押し上げられてしまうため。

### 自動算出の3つのロジック

グループごとに優先ロジックを設定できること(データ不足時は他ロジックへフォールバックする、既定の優先順は「アナリストコンセンサス → EPS成長率ベース → PBR正常化ベース」)。

| ロジック | 計算式 |
|---|---|
| analyst_consensus(アナリストコンセンサス) | アナリスト目標株価平均をそのまま採用 |
| eps_growth(EPS成長率ベース) | 現在株価(購入時点スナップショットの場合は購入価格) × (1 + 予想EPS成長率) |
| pbr_normalization(PBR正常化ベース) | BPS × ターゲットPBR(既定1.0倍) |

### 現状の参考値(グループ別優先ロジック)

| グループ | 優先ロジック |
|---|---|
| 小型株 | eps_growth |
| 中型株 | analyst_consensus |
| 大型株 | analyst_consensus |
| デフォルト | (指定なし、既定順) |

### 達成度算出の無効化条件

ターゲットプライスが購入価格を上回っていない場合、達成度算出は無効(None)として扱うこと。理由: 下落局面ではアナリストコンセンサス等の自動算出値も一緒に下がることがあり、これを無視して達成度を計算すると、深く含み損の状態でも達成度が100%を超えて表示されてしまう(実装時に発見された不具合、要件として明記)。
