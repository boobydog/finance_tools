# 買入タイミング・損切り・利確判定

## 戦略の考え方(要件の背景)

- **「確立モメンタム戦略」を採用する**。複数のシグナル(トレンド転換・出来高急増・決算の市場予想超え)の重複確認により、既に上昇トレンドが確立した銘柄を狙う。まだ底打ちしていない逆張り・反転狙いの銘柄は対象外とする。
- 一方で、単純に「上がっている銘柄を追いかける」だけでは高値掴みのリスクがあるため、過熱・単日急騰を検知する除外条件を必ず設ける(初動は捉えつつ、最終局面での飛び乗りは避ける)。
- 損切りは、単純な下落率だけでなく、**価格(ボラティリティ連動)・ファンダメンタルズ・テクニカルスコアの複合基準**で判定する。
- 利確は、目標株価という主観的な基準に依存しすぎないよう、**価格・テクニカル系の複数条件**に加え、**保有期間の上限に達したら損益に関わらず機械的に決済する第3の判定軸**を独立して持たせる(モメンタム効果は一定期間で減衰しやすいという考え方に基づく規律ルール)。額面上の利確条件を満たしても、手数料・税金を差し引いた実質損益がプラスでなければ利確シグナルとして扱わない。
- 銘柄の時価総額規模(小型株/中型株/大型株)によって値動きの荒さ・モメンタムの持続期間が異なるため、各種しきい値・保有期間上限・トレイリングストップ許容率はセグメントごとに調整できる必要がある。

## 共通の設計: グループ解決

3つの判定はすべて、対象銘柄がどの[スクリーニンググループ](../../requirements/02_glossary.md)の基準を使うかを、以下の優先順で解決する(詳細は [`../architecture.md`](../architecture.md) の「5. スクリーニンググループの解決方針」)。

1. 銘柄が持つタグ(候補になった際の根拠グループ名)に一致する有効グループがあれば、そのグループの基準のみを使う。
2. 一致するタグが無ければ、`is_default=true`のフォールバックグループを使う。
3. 有効なグループが1件も無ければ判定対象外。

## 共通の設計: 複数回の買い増し・部分売却への対応

判定に使う「購入価格」「保有数」は、`trade_history`全体を口座種別問わず集計した**加重平均・合計数量**を使う(直近1回の購入記録だけを見ない)。詳細な設計方針は [`../architecture.md`](../architecture.md) の「7. 複数回の売買への対応方針」を参照。

## 1. 買入タイミング判定

候補(interested)・保有中(holding、買い増し判断用)・売却済(sold、再エントリー判断用)の銘柄が対象(除外・未設定は対象外)。

### 判定ロジック

1. **分類C(条件次第)**: 各条件のうち満たした数を数える。
2. **有力候補判定**: 該当数が「買入シグナル数しきい値」(グループ設定)以上、かつ下記の除外に該当しなければ「有力候補」とする。
3. **分類A(除外条件)**: 1つでも該当すると、シグナル数がしきい値以上でも強制的に除外する(単日急騰・過熱・上抜け直後などの誤検知防止)。
4. **損切りリスク先読みチェック**: 同じグループの損切り判定(分類A/B)を、購入前提のnull値(購入価格・購入時スコアが存在しない状態)のまま評価する。購入価格・スコアに依存する条件(下落率・スコア変化)は自動的に不成立となり、**銘柄自体の状態を示す条件のみ**(上場廃止リスク・監理銘柄・営業利益/EPS成長率の悪化)が働く。これにより、「買った直後に損切り対象になる銘柄」を事前に検知できる。
   - 損切り分類A相当に該当 → 買入タイミングの分類Aと同じ強さで**候補から除外**。
   - 損切り分類B相当に該当 → 除外はせず**警告表示のみ**。

### 参考条件セット

| 分類 | 項目 | 例 | 備考 |
|---|---|---|---|
| C | MA25上抜け | 現在値がMA25を上回っている | 派生値 |
| C | 出来高倍率 | 小型株:3.0倍以上 / 中型株:2.5倍以上 / 大型株・デフォルト:2.0倍以上 | 20日平均比 |
| C | 決算サプライズ(市場予想乖離率) | 0%以上 | |
| A | スクリーニングスコア | 20pt以下で除外 | テクニカルスコア不足の足切り |
| A | RSI | 70以上で除外 | 過熱圏 |
| A | MA25乖離率 | +10%以上で除外 | 追いかけすぎ検知(派生値) |
| A | 前日比騰落率 | +8%以上で除外 | 単日急騰の誤検知防止(派生値) |
| A | MA25上抜け継続日数 | 2日以下で除外 | 上抜け直後(だまし)の除外 |

買入シグナル数しきい値: 全グループ共通で2件(3件中、MA25上抜け・出来高急増・決算サプライズのうち2つ以上)。

### 参考: バリュエーション重視グループ向けの派生値

小型株/中型株/大型株/デフォルトはモメンタム系の条件(MA25上抜け・出来高倍率等)を使うが、割安さ(バリュエーション)を重視するグループでは、代わりに以下の派生値を分類Cの条件として使うことができる。

| 派生値 | 計算式 | 用途 |
|---|---|---|
| peg_ratio | forward_per ÷ eps_growth | 成長率に対する割安さ。`eps_growth`が0以下ならNULL(判定不能) |
| pbr_roe_ratio | pbr ÷ (roe ÷ 100) | 収益性(ROE)に対する割安さ。PBR単体の絶対閾値は高ROE企業ほど正当化される水準が高くなる(会計上PBR=PER×ROE)ため、ROEで正規化する。`forward_per`(予想ベース)と`roe`(実績ベース)は対象期間が異なるため、単純なPERの言い換えにはならない(将来の業績期待が織り込まれる)。`roe`が0以下ならNULL(判定不能) |

いずれも`build_entry_row`(`trade_judgment_engine.py`)内でPythonにより計算する(DBには保存しない)。

## 2. 損切り判定

保有中(holding)銘柄が対象。

### 判定ロジック

1. **分類A**: 1つでも該当すれば優先度**A(即時売却)**。
2. **分類B**: 分類Aに該当せず、1つでも該当すれば優先度**B(回避・撤退検討)**。
3. いずれにも該当しなければ判定なし(継続保有)。

### 参考条件セット

| 分類 | 項目 | 例 | 備考 |
|---|---|---|---|
| A | 上場廃止リスク | true | |
| A | 監理銘柄フラグ | true | |
| A | 購入価格からの下落率 | **-0.5×HV**以下 | HV倍率モード(下記) |
| B | 営業利益前期比 | 0%以下 | |
| B | EPS成長率 | 0%以下 | |
| B | 購入時からのスコア変化 | 小型株:-25pt以下 / 中型株・デフォルト:-20pt以下 / 大型株:-15pt以下 | テクニカルスコアの悪化 |

### HV倍率モード

`value_mode=hv_multiplier`のルールは、設定値をそのまま閾値とせず、**銘柄自身のHV(ヒストリカルボラティリティ)に対する倍率**として扱う。

```
実際の閾値 = 設定値 × その銘柄のHV
```

HVは60日分の日次リターンの標準偏差を年率換算(√250倍)した値(%)。値動きの荒い銘柄ほど下落率の許容幅が自動的に広がり、値動きの穏やかな銘柄ほど早めに損切りされる。現状は全グループ共通で「-0.5×HV」(例: HV=40%の銘柄なら-20%で損切り、HV=80%の銘柄なら-40%で損切り)。

### 派生値の計算式

```
drawdown_percent(下落率) = (現在値 - 購入価格) ÷ 購入価格 × 100
score_diff(スコア変化)   = 現在のテクニカルスコア - 購入時のテクニカルスコア(購入時点でスナップショット、以後固定)
```

## 3. 利確判定

保有中(holding)銘柄が対象。**3つの判定軸**があり、いずれかが成立すれば売却検討となる。

### 判定軸1・2: 分類A(ターゲット到達・過熱・トレンド反転・トレイリングストップ)+ 純損益ゲート

1. **分類A**: いずれか1つでも該当すれば売却検討(複数条件はOR)。想定する条件: ターゲットプライス達成度・PER過熱・トレイリングストップ発動・MA25クロスアンダー(現在値がMA25を下回った、トレンド反転シグナル)。
2. **純損益ゲート**: 分類Aに該当しても、手数料・税引後の想定純損益が黒字でなければ利確シグナルとして扱わない。額面上ターゲットに達していても、手数料・税金を差し引くと損失になる場合の誤検知を防ぐ(計算式は [`trading_costs_and_target_price.md`](trading_costs_and_target_price.md)参照)。

### 判定軸3: 保有期間満了(第3の判定軸、独立)

損切り・利確とは別の第3の判定軸として、「保有期間の上限(グループ設定)を超えたら、損益に関わらず機械的に決済する」という規律ルールを設ける。**純損益ゲートの対象外**とすること(含み損の状態で期間満了しても、損益に関わらず決済対象として表示する。純損益ゲートと混ぜると「損益に関わらず決済する」という趣旨に反するため)。保有日数は**最初に建てた買付日**(複数回買い増しした場合は最も古い購入日)から起算し、JST(Asia/Tokyo)の日付で計算する。

### 参考条件セット

| 分類 | 項目 | 小型株 | 中型株 | 大型株 | デフォルト |
|---|---|---|---|---|---|
| A | ターゲットプライス達成度 | 100%以上 | 100%以上 | 100%以上 | 100%以上 |
| A | PER(予想、過熱) | 65倍以上 | 45倍以上 | 30倍以上 | 60倍以上 |
| A | トレイリングストップ発動 | true | true | true | true |
| A | MA25割れ | true | true | true | true |
| - | 保有期間上限 | 90日 | 180日 | 270日 | 180日 |
| - | トレイリングストップ許容下落率 | 15% | 12% | 8% | (全体設定にフォールバック、既定10%) |

PERの過熱閾値はセグメントが小さいほど緩め(小型株は高PERが許容されやすい)に設定するとよい。保有期間上限・トレイリングストップ許容率は、値動きの荒さ・モメンタムの持続しやすさに応じてセグメント別に調整する(小型株は反転が早い・値動きが荒いため短め/広め、大型株は持続しやすい・安定しているため長め/狭め)。

MA25クロスアンダー(is_below_ma25)は、目標株価という主観的な基準に頼らず「トレンドが崩れたら機械的に手仕舞う」という技術的な反転シグナルであり、確率論的なモメンタム戦略の考え方に沿った条件として全グループに設定している。

### トレイリングストップ

保有中の最高値から一定割合下落したら発動。

```
逆指値ライン = 保有期間中の最高値 × (1 - 許容下落率)
発動条件: 現在値 <= 逆指値ライン
```

許容下落率はグループごとに設定でき、未設定のグループは全体設定にフォールバックする。

### 派生値の計算式

```
ma25_deviation_percent(MA25乖離率)   = (現在値 - MA25) ÷ MA25 × 100
daily_change_percent(前日比騰落率)   = (現在値 - 前日終値) ÷ 前日終値 × 100
achievement_percent(達成度)          = 現在値 ÷ 有効なターゲットプライス × 100
is_below_ma25(MA25割れ)              = 現在値 < MA25
```

ターゲットプライスが購入価格を上回っていない場合、達成度算出は無効(None)として扱うこと(下落局面で目標も一緒に下がり、達成率が実態と無関係に押し上げられるのを防ぐため)。ターゲットプライスの算出ロジックは [`trading_costs_and_target_price.md`](trading_costs_and_target_price.md) を参照。

## 4. 統合判定(優先順位)

複数の判定結果を1つの統合バッジとして画面表示する場合、以下の優先順位でマージすること(上にあるほど優先)。

1. 損切り優先度A → **即時売却**
2. 損切り優先度B → **回避・撤退検討**
3. 保有期間満了 → **保有期間満了**(純損益に関わらず表示。損切り優先度が付いている場合はそちらが優先表示されるが、詳細画面には両方表示する)
4. 利確シグナル(純損益ゲート通過) → **利確**
5. 買入タイミング有力候補 → **買い候補**
6. 上記いずれにも該当しない → 継続保有(バッジなし)
