# finance_tools

日本株売買予測ツール（仮）

## セットアップ

認証情報はテンプレートファイル(`*.example`)をコピーして作成してください(いずれもgit管理対象外です)。

```
cp .env.example .env
cp mysql/client.cnf.example mysql/client.cnf
cp mysql/secrets/root_password.txt.example mysql/secrets/root_password.txt
cp mysql/secrets/password.txt.example mysql/secrets/password.txt
```

各ファイルの値を必要に応じて書き換えたうえで、`mysql/client.cnf` と `mysql/secrets/*.txt` の
パスワードは一致させてください(`mysql/secrets/password.txt` が実際にDBへ設定される
アプリ用ユーザーのパスワードです)。

```
make up
```

## 概要

本システムは、個別株の裁量判断に頼りすぎず、**機械的・再現可能なルールで「買い時」「損切り」「利確」を判定する**ことを目指した投資支援ツールである。日本株(東京証券取引所上場銘柄、既定の銘柄ユニバースは日経225構成銘柄)を対象に、以下の4つの判定機能を提供する。

- **候補スクリーニング(自動候補化)**: ROE・自己資本比率・売上高成長率等のファンダメンタルズ指標、またはテクニカルスコアが基準を満たした銘柄を自動で「候補」にする。
- **買入タイミング判定**: MA25上抜け・出来高急増・決算サプライズ等の複数シグナルの重複確認により、既に上昇トレンドが確立した銘柄を狙う「確立モメンタム戦略」で買い時を判定する(逆張り・底打ち狙いは対象外)。
- **損切り判定**: 銘柄自身のヒストリカルボラティリティ(HV)に連動する下落率基準、ファンダメンタルズの悪化、テクニカルスコアの悪化という複合基準で判定する。
- **利確判定**: 目標株価到達・PER過熱・トレイリングストップ・MA25クロスアンダーによる価格/テクニカル軸に加え、保有期間の上限に達したら損益に関わらず機械的に決済する第3の判定軸を独立して持つ。額面上の利確条件を満たしても、手数料・税金を差し引いた実質純損益がプラスでなければ利確シグナルとして扱わない。

いずれの判定基準も、銘柄の時価総額規模(小型株/中型株/大型株)ごとに異なる「スクリーニンググループ」単位で調整でき、設定画面から変更できる。複数回の買い増し・部分売却、NISA/課税口座の分離管理にも対応している。
